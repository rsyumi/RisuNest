# RisuNest v1.3.0

## English

### New Features

- Applied RisuAI v2026.10.292 changes.
- Added database compaction (reclaims unused SQLite space).

### Improvements

- Changed module imports to leave out MCP settings.
- Allowed plugins to replace other plugins after user confirmation.
- Changed startup text to appear in the device language.
- Allowed plugins to convert to WebP even in environments that do not support WebP conversion.
- Improved restore and storage performance.
- Improved error messages and logging.

### Fixes

- Fixed some API requests, such as Anthropic, being rejected.
- Fixed responses, Lua buttons, and similar work stopping after leaving the app on Android.
- Fixed Google Translate failing with error 429 in some environments.
- Fixed storage growing continuously when plugins repeatedly saved large data.
- Fixed permanent character deletion failing or being reported as failed.
- Fixed RisuAI/PocketRisu compatible exports failing with some settings.
- Fixed some RisuAI modules failing to import.
- Fixed lorebooks and persona descriptions loaded from Lua not reflecting changed variables.
- Fixed Data check failing to fix some issues.
- Fixed the code block menu being hidden behind pop-up windows.

## 한국어

### 새 기능

- RisuAI v2026.10.292 변경 사항 반영.
- 데이터베이스 압축 기능(SQLite 공간 확보 기능) 추가.

### 개선

- 모듈 가져오기 시 MCP 설정은 가져오지 않도록 변경.
- 플러그인이 사용자 확인 후 다른 플러그인을 교체할 수 있도록 개선.
- 시작 화면 문구가 기기 언어로 표시되도록 개선.
- WebP 변환이 지원되지 않는 환경에서도 플러그인이 WebP로 변환할 수 있도록 개선.
- 복원 및 저장 성능 개선.
- 오류 표현 및 로깅 개선.

### 수정

- Anthropic 등 일부 API 요청이 거부되던 문제 수정.
- Android에서 앱을 벗어나면 응답 생성이나 Lua 버튼 등의 작업이 멈추던 문제 수정.
- 일부 환경에서 Google 번역이 429 오류로 실패하던 문제 수정.
- 플러그인이 큰 데이터를 반복 저장할 때 저장 공간이 계속 늘어나던 문제 수정.
- 캐릭터 영구 삭제가 실패하거나 실패로 표시되던 문제 수정.
- 일부 설정에서 RisuAI/PocketRisu 호환 내보내기에 실패하던 문제 수정.
- 일부 RisuAI 모듈을 가져오지 못하던 문제 수정.
- Lua에서 불러온 로어북, 페르소나 설명에 변경한 변수가 반영되지 않던 문제 수정.
- 데이터 점검에서 일부 문제를 고치지 못하던 문제 수정.
- 코드 블록 메뉴가 팝업 창 뒤에 가려지던 문제 수정.
