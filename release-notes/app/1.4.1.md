# RisuNest v1.4.1

## English

### Improvements

- Improved drag reordering and its UI in chats, lorebooks, presets, prompts, and more.
- Fixed touch issues across the app, including dragging, and improved the touch UI.
- Allowed long pressing to do what only a right click did, such as opening the pop-up editor and removing custom GUI elements.
- Allowed keeping the desktop data folder in another location through a junction or symbolic link.
- Improved signing in again to external storage.
- Improved Sync server sync performance, and a brief connection failure no longer shows a warning.

### Fixes

- Fixed presets, prompts, trigger scripts, and similar lists not being reorderable by touch.
- Fixed some Lua scripts with many local variables failing to run.
- Fixed the message menu needing two taps to open after a tap elsewhere closed it.
- Fixed bookmark, branch, and similar menu items on the first message causing errors.
- Fixed the HypaV3 translate buttons not responding to a mouse in the desktop app on touch screens.
- Fixed the progress not updating correctly during the first download from the Sync server.
- Fixed sync error notices and resuming when several external storages are used.
- Fixed Lua scripts occasionally losing their global variables after a timeout.
- Fixed a duplicate Close Window item in the macOS menu bar.

## 한국어

### 개선

- 채팅, 로어북, 프리셋, 프롬프트 등 드래그를 통한 순서 변경 UI 및 기능 개선.
- 드래그를 포함하여 전반적인 터치 조작 문제 수정 및 UI 개선.
- 팝업창 편집기 열기, 커스텀 GUI 요소 삭제 등 우클릭으로만 되던 동작을 길게 눌러 사용할 수 있도록 개선.
- 데스크톱에서 데이터 폴더를 정션이나 심볼릭 링크로 다른 위치에 둘 수 있도록 개선.
- 외부 저장소에 다시 로그인하는 과정 개선.
- Sync 서버 동기화 성능 개선 및 일시적인 연결 실패에는 경고가 표시되지 않도록 개선.

### 수정

- 프리셋, 프롬프트, 트리거 스크립트 등에서 터치로 순서 변경이 되지 않던 문제 수정.
- 지역 변수를 많이 쓰는 일부 Lua 스크립트가 실행되지 않던 문제 수정.
- 다른 곳을 눌러 메시지 메뉴를 닫은 경우 메뉴 버튼을 두 번 눌러야 열리던 문제 수정.
- 첫 메시지에서 북마크, 분기점 등의 메뉴가 표시되어 오류가 나던 문제 수정.
- 터치스크린에서 데스크톱 앱을 쓰는 경우 HypaV3 번역 버튼이 마우스 클릭에 반응하지 않던 문제 수정.
- Sync 서버에서 처음 데이터를 받을 때 진행률이 제대로 반영되지 않던 문제 수정.
- 여러 외부 저장소 사용 시 발생하던 동기화 오류 안내 및 재개 문제 수정.
- 간혹 실행 시간 초과 후 Lua 스크립트의 전역 변수가 초기화되던 문제 수정.
- macOS 메뉴 막대에 창 닫기 항목이 중복 표시되던 문제 수정.
