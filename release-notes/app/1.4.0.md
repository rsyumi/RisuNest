# RisuNest v1.4.0

## English

### New Features

- Added a module menu to the sidebar and redesigned the module activation UI.

### Improvements

- Allowed importing several characters or modules at once.
- Allowed turning off automatic snapshots and setting how many snapshots to keep.
- Improved the error log screen and added saving the whole log to a file.
- Added Data check repairs that select the first preset or persona and give a module a new ID.
- Data that chats and external storage backups no longer use is now cleaned up sooner.
- Improved storage screen loading speed.
- Changed backup, export, and error log file names to use local time.
- Changed failed RisuAI/PocketRisu compatible exports to name the item that caused the failure.
- Changed the backup restore confirmation to show attachment references without files.
- Improved the readability of secondary text colors on RisuNest screens.
- Improved restore, import, and storage performance.
- Improved error messages and logging.

### Fixes

- Fixed dialogs opened during startup appearing before the app lock screen.
- Fixed the reset and backup restore screens being hidden behind the logo screen on iOS and macOS.
- Fixed some links in chat messages reloading the app.
- Fixed the persona prompt not being sent correctly when using Bind Persona.
- Fixed saves occasionally failing in chats that use chat variables.
- Fixed an error appearing when stopping a Google or OpenAI response.
- Fixed images used inside the text of archived characters, such as chat messages, being deleted by the unused file cleanup.
- Fixed other app operations stalling while snapshots were being created, listed, or deleted.
- Fixed RisuAI/PocketRisu compatible exports failing with some settings, such as a cleared lorebook insertion order.
- Fixed some lorebook entries added by Lua or card imports causing errors in the editor or the prompt.
- Fixed notifications not being allowed from the iOS Platform page.
- Fixed a debugging feature making the app use more memory on iOS.
- Fixed the app possibly being force-closed on iOS when the screen reloads.
- Fixed UI issues in the pop-up editor.

## 한국어

### 새 기능

- 사이드바에 모듈 메뉴 추가 및 모듈 활성화 UI 개편.

### 개선

- 여러 캐릭터나 모듈을 한 번에 가져올 수 있도록 개선.
- 자동 스냅샷을 끄거나 보관 수를 지정할 수 있도록 개선.
- 오류 로그 화면 개선 및 전체 로그 파일 저장 기능 추가.
- 데이터 점검에 첫 프리셋 선택, 첫 페르소나 선택, 모듈에 새 ID 부여 기능 추가.
- 채팅과 외부 저장소 백업에서 더 이상 사용하지 않는 데이터가 더 빨리 정리되도록 개선.
- 저장 공간 화면 로딩 속도 개선.
- 백업, 내보내기, 오류 로그 파일 이름에 현지 시간을 쓰도록 변경.
- RisuAI/PocketRisu 호환 내보내기 실패 시 원인이 된 항목을 표시하도록 개선.
- 백업 복원 확인 창에 파일이 없는 첨부 파일 참조를 표시하도록 개선.
- RisuNest 화면의 보조 문구 색상 가독성 개선.
- 복원, 가져오기, 저장 성능 개선.
- 오류 표현 및 로깅 개선.

### 수정

- 앱 잠금 사용 시 앱 시작 중 열린 대화상자가 잠금 화면보다 먼저 표시되던 문제 수정.
- iOS와 macOS에서 초기화 및 백업 복원 화면이 로고 화면에 가려지던 문제 수정.
- 채팅 메시지의 일부 링크를 누르면 앱이 다시 로드되던 문제 수정.
- 페르소나 바인드 사용 시 페르소나 프롬프트가 제대로 전달되지 않던 문제 수정.
- 채팅 변수를 사용하는 채팅에서 간혹 저장에 실패하던 문제 수정.
- Google, OpenAI 응답 생성을 중지할 때 오류 창이 표시되던 문제 수정.
- 보관한 캐릭터의 채팅 등 텍스트 안에서 쓰인 이미지가 사용하지 않는 파일 정리에서 삭제되던 문제 수정.
- 스냅샷을 만들거나 조회, 삭제하는 동안 앱의 다른 작업이 멈추던 문제 수정.
- 로어북 배치 순서를 비운 경우 등 일부 설정에서 RisuAI/PocketRisu 호환 내보내기에 실패하던 문제 수정.
- Lua나 카드 가져오기로 추가된 일부 로어북 항목이 편집 화면이나 프롬프트에서 오류를 일으키던 문제 수정.
- iOS 플랫폼 화면에서 알림을 허용할 수 없던 문제 수정.
- iOS에서 디버깅 기능으로 인해 메모리를 더 점유하던 문제 수정.
- iOS에서 화면을 다시 불러올 때 앱이 강제 종료될 수 있던 문제 수정.
- 팝업창 편집기의 UI 문제 수정.
