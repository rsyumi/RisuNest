# RisuNest v1.4.0

## English

### New Features

- Added a sidebar module menu and redesigned the module activation UI.

### Improvements

- Allowed importing several characters or modules at once.
- Allowed turning off automatic snapshots and limiting how many are kept.
- Improved the error log screen and added saving the whole log.
- Added Data check repairs for the first preset or persona and module IDs.
- Unused data is now cleaned up sooner.
- Backup, export, and error log file names now use local time.
- Failed RisuAI/PocketRisu compatible exports now name the cause.
- Backup restore confirmation now lists attachment references without files.
- Improved secondary text readability on RisuNest screens.
- Improved storage screen loading, restore, import, and storage performance.
- Improved error messages and logging.

### Fixes

- Fixed startup dialogs appearing before the app lock screen.
- Fixed the reset and backup restore screens hidden behind the logo on iOS and macOS.
- Fixed some chat message links reloading the app.
- Fixed the persona prompt not being sent correctly with Bind Persona.
- Fixed saves occasionally failing in chats using chat variables.
- Fixed an error when stopping a Google or OpenAI response.
- Fixed unused file cleanup deleting images used in archived characters' chats.
- Fixed other operations stalling during snapshot work.
- Fixed RisuAI/PocketRisu compatible exports failing with some settings.
- Fixed some lorebook entries causing errors in the editor or the prompt.
- Fixed notifications not being allowed from the iOS Platform page.
- Fixed a debugging feature using extra memory on iOS.
- Fixed the app possibly being force-closed on iOS when reloading.
- Fixed UI issues in the pop-up editor.

## 한국어

### 새 기능

- 사이드바에 모듈 메뉴 추가 및 모듈 활성화 UI 개편.

### 개선

- 여러 캐릭터나 모듈을 한 번에 가져올 수 있도록 개선.
- 자동 스냅샷을 끄거나 보관 수를 지정할 수 있도록 개선.
- 오류 로그 화면 개선 및 전체 로그 파일 저장 기능 추가.
- 데이터 점검에 첫 프리셋 선택, 첫 페르소나 선택, 모듈에 새 ID 부여 기능 추가.
- 사용하지 않는 데이터가 더 빨리 정리되도록 개선.
- 백업, 내보내기, 오류 로그 파일 이름에 현지 시간을 쓰도록 변경.
- RisuAI/PocketRisu 호환 내보내기 실패 시 원인이 된 항목을 표시하도록 개선.
- 백업 복원 확인 창에 파일이 없는 첨부 파일 참조를 표시하도록 개선.
- RisuNest 화면의 보조 문구 색상 가독성 개선.
- 저장 공간 화면 로딩, 복원, 가져오기, 저장 성능 개선.
- 오류 표현 및 로깅 개선.

### 수정

- 앱 잠금 사용 시 앱 시작 중 열린 대화상자가 잠금 화면보다 먼저 표시되던 문제 수정.
- iOS와 macOS에서 초기화 및 백업 복원 화면이 로고에 가려지던 문제 수정.
- 채팅 메시지의 일부 링크를 누르면 앱이 다시 로드되던 문제 수정.
- 페르소나 바인드 사용 시 페르소나 프롬프트가 제대로 전달되지 않던 문제 수정.
- 채팅 변수를 사용하는 채팅에서 간혹 저장에 실패하던 문제 수정.
- Google, OpenAI 응답 생성을 중지할 때 오류 창이 표시되던 문제 수정.
- 보관한 캐릭터의 채팅에 쓰인 이미지가 사용하지 않는 파일 정리에서 삭제되던 문제 수정.
- 스냅샷을 만들거나 조회, 삭제하는 동안 앱의 다른 작업이 멈추던 문제 수정.
- 일부 설정에서 RisuAI/PocketRisu 호환 내보내기에 실패하던 문제 수정.
- 일부 로어북 항목이 편집 화면이나 프롬프트에서 오류를 일으키던 문제 수정.
- iOS 플랫폼 화면에서 알림을 허용할 수 없던 문제 수정.
- iOS에서 디버깅 기능이 메모리를 더 점유하던 문제 수정.
- iOS에서 화면을 다시 불러올 때 앱이 강제 종료될 수 있던 문제 수정.
- 팝업창 편집기의 UI 문제 수정.
